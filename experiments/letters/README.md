# Коллекция букв textula

## Редактирование коллекции

Редактор сохранён в этой папке. На macOS можно запустить двойным кликом `start-editor.command`: он откроет уже работающий редактор или создаст постоянное Python-окружение `.editor-venv`, установит Pillow и запустит сервер. При первом создании окружения нужен интернет. Окно терминала сервера должно оставаться открытым. Текущие исправления и снимок редактора сохранены также в `editor-snapshots/revision-0123.zip`; это резервная копия, последующие правки по-прежнему записываются в обычные файлы проекта.

Запуск локального сервера с сохранением в проект (из корня репозитория):

```sh
python3 experiments/letters/serve.py --port 5173
```

Открыть `http://127.0.0.1:5173/experiments/letters/`. Обычный статический сервер показывает коллекцию, но не принимает правки.

Вход: на главной странице откройте меню ☰ → «Админ», введите код, затем в панели модерации нажмите «Редактор букв». Ссылка открывается в той же вкладке и использует проверяемую сессию администратора. Без входа редактор заблокирован; локальный сервер также проверяет сессию перед чтением служебного состояния и сохранением.

Нажмите вариант: можно изменить букву и алфавит, переместить рамку или потянуть её за угол, нарисовать новую рамку за пределами старой, ввести координаты в пикселях. Масштаб помогает работать с мелкими буквами. Предпросмотр обновляется сразу. **«Сохранить в коллекцию»** записывает изменения в файлы проекта, создаёт исправленный PNG и обновляет каталог и ZIP. До нажатия кнопки изменения остаются черновиком в форме.

**«Скрыть вариант»** помечает его для исключения; нажмите «Сохранить». Файлы не удаляются. Чтобы вернуть вариант, включите «Показать скрытые», откройте его, нажмите «Вернуть в коллекцию» и сохраните. «Отменить изменения» возвращает форму к последнему сохранению; «Вернуть исходный вариант» — к первоначальной разметке, которую также нужно сохранить.

- `editor-edits.json` — постоянные пользовательские исправления по стабильным ID вариантов: буква, алфавит, рамка, скрытие, время и версия. Этот файл нужно читать агенту перед продолжением работы; браузерное хранилище для правок не используется.
- `editor-history.jsonl` — история сохранённых правок. Создаётся при первом сохранении.
- `manifest-base.json` — первоначальная разметка для восстановления; `manifest-all.json` — действующая разметка с правками и признаками скрытия.
- `edited/` — исправленные кропы с новыми именами; исходные кропы и фотографии сохраняются.
- В ZIP входят только нескрытые варианты и манифест с актуальными буквами и рамками.
- `collection_editor.py` — применение правок; `serve.py` — локальный HTTP-сервер редактора. Сервер принимает запись только с локального интерфейса.

`build_collection.py` повторно применяет сохранённые исправления после сборки, поэтому пересборка не сбрасывает ручную правку. `processed-photos.json` остаётся реестром исходного извлечения; пользовательское скрытие не делает фотографию «необработанной».

## Тест надписей

Отдельная страница `http://127.0.0.1:5173/experiments/letters/play.html` позволяет вводить надпись и подбирать для каждой позиции варианты букв. Нажатие на букву открывает выбор; «Откуда эта буква» показывает исходник и рамку. «Перемешать» сохраняет текст и меняет каждый кроп, для которого есть альтернатива. Единственный вариант остаётся прежним. Кириллица и латиница не смешиваются; отсутствующие буквы отображаются пунктиром.

Страница берёт только нескрытые варианты из актуальной коллекции и учитывает исправленные буквы и рамки. После работы в редакторе коллекция обновляется при открытии страницы и возвращении в окно. Тестовая страница не записывает правки в коллекцию: текущая надпись и выбранные варианты хранятся отдельно в браузере. Файлы: `play.html`, `play.js`, `play.css`.

## Добавление новых фотографий

`processed-photos.json` — постоянный реестр всех 74 просмотренных снимков, включая 34 источника с буквами и снимки без пригодных букв. Для каждого сохранены ID, название, URL, дата просмотра, SHA-256 локального файла, результат, число кропов и их идентификаторы.

Перед следующим пополнением:

```sh
python3 experiments/letters/check_new_photos.py
```

Команда читает публичную базу сайта (обложки и дополнительные одобренные фото) и записывает только новые ссылки в `pending-photos.json`. Замена обложки у старой находки тоже попадёт в очередь. Уже просмотренные фото, в том числе без букв, пропускаются. Реестр автоматически не пополняется: запись добавляется после фактического просмотра и нарезки. Замена содержимого под неизменным URL обнаруживается при сравнении нового SHA-256; сама проверка ссылок не скачивает изображения.

Проверка без интернета по сохранённому списку:

```sh
python3 experiments/letters/check_new_photos.py --input experiments/letters/all-sources.json
```

Инструкции для следующего пополнения сохранены также в `AGENTS.md` этой папки. Сборка коллекции остановится, если в список источников добавлено ещё не просмотренное фото.

Открыть через локальный HTTP-сервер: `/experiments/letters/`.

Проверены все 74 обложки одобренных находок, доступные через публичную базу сайта на 10 ноября 2026 года. Дополнительных одобренных фотографий публичный API не вернул. Список сопоставлен с 63 локальными страницами находок. Итоги каждого просмотра — в `review.json`.

В коллекцию включены читаемые отдельные буквы с вывесок, табличек, стикеров, граффити, люка и музейной доски. Мелкий служебный текст не нарезан целиком; обрезанные и неоднозначные символы пропущены. Это коллекция пригодных вариантов, а не полная транскрипция текста на каждом снимке. Рамки проверены вручную на контактных листах. На декоративных и соединённых буквах внутри прямоугольника могут оставаться части соседних символов, ветки и повреждения. Перспектива, фон, цвет и ориентация сохранены.

- `index.html`, `collection.js`, `collection.css` — каталог с фильтрами.
- `manifest-all.json` — используемые варианты, символ, алфавит, исходник и рамка в пикселях ориентированного изображения.
- `collection.zip` — варианты разложены по алфавиту и букве; пути `file` во вложенном манифесте соответствуют архиву.
- `all-sources.json`, `sources/`, `thumbnails/` — список, исходные снимки и уменьшенные копии.
- `selections.py` — ручная разметка рамок в копиях снимков с максимальной стороной 1000 px без увеличения.
- `build_collection.py` — воспроизводимая нарезка, манифест, архив и листы проверки. Требует Pillow.
- `summary.json` — итоговые числа и отсутствующие буквы.
- `qa-*.jpg`, `contact-*.jpg` — контактные листы.

Первый набор из 19 букв и его файлы сохранены: `sample.html`, `crops/`, `manifest.json`, `letters.zip`, `build.py`, `preview.jpg`. Старый `build.py` создаёт первоначальную страницу, поэтому для обновления общей коллекции используйте `build_collection.py`. Черновые файлы нарезки также оставлены; актуальный состав определяется `manifest-all.json`.

```sh
PYTHONPATH=/tmp/textula-python python3 experiments/letters/build_collection.py
```

Pillow установлен во временной папке текущей сессии; для повторного запуска позднее его потребуется установить в своё Python-окружение. Скрипт не удаляет файлы. Конструктор слов пока не добавлен.

Публичный переход к конструктору надписей находится в меню ☰ главной страницы — «Написать городом». На публичной странице нет переходов в редактор букв.

### Только чёткие буквы

На странице надписей есть необязательный фильтр «Только чёткие». При открытии он выключен: доступны все нескрытые варианты. Включение сохраняет текст и уже выбранные подходящие кропы, заменяя остальные чёткими. Выбор начертания и «Перемешать» используют тот же фильтр. Если для символа нет чёткого кропа, показывается пунктир и сообщение; размытый вариант автоматически не подставляется.

`letter-quality.json` хранит оценку каждого кропа, связанную с ID и конкретным именем файла. `build_letter_quality.py` проверяет разрешение и выраженность границ при высоте 100 px, с визуально проверенными исключениями для мягких фотографий. Это практический отбор, а не оценка художественной ценности или повреждений букв. Неизвестные/изменённые кропы не проходят фильтр до пересчёта. При сохранении в редакторе и полной пересборке классификация пересчитывается автоматически. Самостоятельный запуск:

```sh
PYTHONPATH=/tmp/textula-python python3 experiments/letters/build_letter_quality.py
```

### Ручная отметка чёткости

В карточке редактора есть галочка «Чёткая буква». Измените её и нажмите «Сохранить в коллекцию»: ручная отметка true/false записывается в `editor-edits.json` как `clear_override` и имеет приоритет над автоматической классификацией. «Автоматическая оценка» возвращает `clear_override: null`; это действие также нужно сохранить. В каталоге видны текущая оценка и её источник (вручную / авто).

Ручная отметка сохраняется при изменении рамки, повторной сборке и перезапуске редактора. Старые правки без этого поля продолжают работать; сохранение из старой вкладки не стирает уже заданную ручную оценку. Публикация исправлений чёткости выполняется тем же способом, что и публикация остальных правок букв.
